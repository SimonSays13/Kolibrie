# swiftColibri

A native macOS menu bar app, written entirely in Swift, for installing, configuring and running [Colibri](https://github.com/JustVugg/colibri) and pointing coding harnesses at its models.

Status: planning. No code yet.

## Planned scope

- Install Colibri and its models, with download progress and Metal setup
- Start, stop and switch models from the menu bar
- Launch Claude Code, Codex, OpenCode, OpenClaw, Hermes Agent, Pi, Mistral Vibe, Copilot CLI and DeepSeek harness against a running model
- A settings UI covering every Colibri configuration option
- Colibri update checks, and run at login with or without a model loaded

## Requirements

macOS 15 or later on Apple Silicon.
